HandsOn Tree LIS

You are given a tree of size n rooted at node 1.

Let’s define lis(u) as the maximum size of a set of nodes (let’s call this set s), that satisfies all the following conditions:

  1. For each pair of nodes (a, b) in s such that a < b, either a is an ancestor of b, or b is an ancestor of a.
  2. The node u belongs to the set, and is the closest node to the root in that set.
  3. If we sort the nodes of s in an increasing order of their depth, we get an increasing sequence.

Find the sum of lis(i) for all i from 1 to n. Since the answer can be large return it modulo 10⁹ + 7.

Input Format

  • The first line contains a single integer n, the number of nodes in the tree.
  • Each of the next n − 1 lines contains two integers u and v describing an undirected edge between nodes u and v.
  • It is guaranteed that these edges form a tree rooted at node 1.

Output Format

Print a single integer — the value ∑i=1n lis(i) modulo 10⁹ + 7.

Constraints

  • 1 ≤ n ≤ 2 × 105
  • 1 ≤ u, v ≤ n
  • The given edges always form a valid tree.

Sample Input 1

5
1 2
1 3
3 4
3 5

Sample Output 1

7

Explanation

For each node u, we consider the largest valid set s that contains u and satisfies all the conditions. Summing these values over all nodes gives the answer 7 for this example.
